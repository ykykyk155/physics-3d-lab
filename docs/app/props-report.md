# 实物化试点（七个场景）报告

## 一、做了什么

新建 `exp/props.js`：把「积木方块」换成一眼能认出的教学仪器。每个工厂内部用
`mergeByMaterial` 把同材质静态构件合成 1 个 draw call，只把需要独立运动的零件
（轮子、指针、弹簧、灯丝、液柱）单独留 mesh。

材质统一到 `MATERIALS` 常驻单例（颜色/粗糙度/金属度/透明度为唯一来源，场景内不二次调色），
每个材质标 `userData.shared = true`，`registerMaterials(ctx)` 里调 `ctx.keep(...)` 登记——
符合 CEO 定的「标记 + 登记」双保险与客户端工程师的三层资源归属。

会随参数/动画改自身属性的材质（灯丝亮度、玻璃泡透明度、液柱、火焰）用 `matClone()` 克隆，
克隆体是场景私有，交外壳正常释放，绝不串场景。

## 三、数值不走外形

按 CEO 要求：**外形尺寸只由物理尺寸决定，数值一律用仪表化方式表现**。

- A2 质量：不放大车身（会让人以为换了辆大车），改为**车上摞配重块**，质量越大块越多。
- D1 电流：**灯泡亮度 + 电流表指针**，不缩放灯泡。
- A3 摩擦力：**弹簧测力计拉伸量 + 红指针**，不改木块大小。
- B5 口径：透镜光学组件缩放（支架不动）；遮半用遮板 + 像变暗。
- F3 温升：**烧杯液柱高度**，不缩放烧杯。
- 车轮随位移滚动、飞轮随曲轴转——运动件真动。

## 四、验收数据

- 25 场景全量切换 + 101 次枚举分段点击：**控制台 0 报错**。
- 稳态 draw call 最大值 **38**（F3），全部 ≤60；F3 播放峰值实测 **51**，仍 ≤60。
- 三角形最大值 **13780**（F3），全部 <200k。
- 参数复核脚本 `verify-fixes.mjs`：**25/25 通过，0 仍失效**（A2 mass、B5 cover/source、D1/D6/F3 等全部仍联动）。

## 六、第二轮「像不像」返工（按 CEO + 设计总裁意见）
