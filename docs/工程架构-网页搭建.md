## 3. 模块拆分：实验即插件

核心是一个统一接口，所有实验实现它，框架代码对实验数量无感知：

```ts
// core/types.ts —— 参数控件两种：数值滑杆 / 离散档位枚举（与附录 A JSON、设计总裁组件规则一致）
export interface NumberParam {
  type?: 'number';
  key: string;               // "mass"
  label: string;             // "质量 m"
  min: number; max: number; step: number;
  unit?: string;             // "kg"
  default: number;
}

export interface EnumParam {
  type: 'enum';
  key: string;
  label: string;
  options: { label: string; value: string }[];
  default: string;
}                            // UI 渲染：2~4 档分段按钮，5~6 档下拉

export type ParamSchema = NumberParam | EnumParam;

export interface ExperimentContext {
  scene: THREE.Scene;
  onParam(key: string, value: number | string): void;   // 参数→模型更新（滑杆数值 + 枚举档位）
  step(dt: number): void;                      // 每帧；dt 为已乘速度倍率的仿真步长
  emitReadout(v: Record<string, number | string>): void; // 推读数给 UI；键=读数卡标题字段
}

export interface Experiment {
  id: string;
  name: string;
  module: 'mechanics' | 'electricity' | 'optics' | 'acoustics' | 'thermal';
  chapter: string;                            // 教材章节
  params: ParamSchema[];
  supportsPlayback?: boolean;                 // false 时工具条置灰显示"本实验无需播放"
  build(ctx: ExperimentContext): void;
  reset(): void;                              // 恢复默认 + 清仿真内部状态（如单摆摆角）
  dispose(): void;                            // 释放 GPU 资源
}
```

新增一个实验 = 在 `experiments/<模块>/` 新建一个文件并实现接口，左侧面板自动出现该条目，零框架改动。25 个 P0 实验（五模块）即可并行走（附录 A 清单对号入座）。

**数据源约定**：`docs/附录A-实验清单.json` 即 `experiments.json`（`id/module/priority/name/chapter/quantities/params[]/formula/result/secondaryResult?/phenomenon/defaultSpeed?`），registry 按 id 懒加载对应 chunk。UI 元数据（标签、范围、枚举选项、默认值、读数卡标题）全部取自 JSON 自动渲染，实验代码只负责 `build/step/reset` 与物理计算——**不许手写 UI**。

**懒加载**：registry 用 `import.meta.glob('./experiments/**/*.ts')`，切换到某实验才拉对应 chunk，首屏只加载引擎 + 模块目录。

## 4. 状态管理方案

自研发布-订阅 store（不引 Redux/Zustand，复杂度不匹配）：

```ts
interface PlaybackState {
  playing: boolean;   // 暂停只停仿真时间，相机和调参照常响应
  speed: number;      // 2× 只影响仿真步进，不影响帧率
}

interface AppState {
  module: ModuleId;                      // 'mechanics' | 'electricity' | 'optics' | 'acoustics' | 'thermal'
  experimentId: string | null;
  params: Record<string, number | string>;   // 数值滑杆 + 枚举控件混合写入
  playback: PlaybackState;
  readouts: Record<string, number | string>; // 实验写入，UI 订阅显示
}
```

- 单向数据流：UI 操作 → `store.setState` → 订阅者各自响应，禁止反向直改 UI。
- 选择器订阅：组件只订阅自己关心的切片（如 readouts.t），避免全量刷新。
- 读数显示 100ms 节流合并写 DOM，防止每帧 textContent 抖动。

## 5. 左侧 UI ↔ three.js 通信（全部走 store，不散布事件总线）

```
用户拖滑杆 → paramSliders 写 store.params / 工具条写 store.playback
                ↓ store 订阅
engine ── params 变化 ──→ currentExperiment.onParam(key, value) → 模型实时更新
engine ── experimentId 变化 ──→ sceneManager.switchTo(id)（懒加载 + dispose 旧的）
engine ── playback 变化 ──→ 仿真时钟启停 / 步长乘 speed（帧循环不停）
experiment ── step 内 emitReadout ──→ engine 写 store.readouts ──→ readouts.ts 显示
```

- **引擎对 UI 只暴露五个方法**（与 3D 渲染师对齐）：`mount / setExperiment / setParams / setPlayback / reset`，全部由 store 订阅驱动，**引擎不回写任何控制状态**。
- **高频例外**：OrbitControls 直接绑在 `renderer.domElement` 消费 pointer/触摸事件，不经过 store（每帧 60 次的事件不入全局状态）。
- 帧循环用 `renderer.setAnimationLoop`，`clock.getDelta()` 限幅 dt ≤ 0.05s，防 tab 切回后物理跳变；暂停仅停仿真时间累加，渲染循环照常跑。
- 切换实验时 `playing` 重置 true、`speed` 保留上次选择；色彩 token（背景/雾 `#0B1120`、五科识别色，含热学 `--accent-thermal`）由 `styles/tokens.css` 单一来源下发，3D 侧只读不另定。

### 5.1 与设计总裁 UI 规范的对接口径（通信契约）

- UI 层只向 store 写两类数据：`setExperiment(id)` 和 `setParams(参数对象)`；3D 引擎订阅后驱动场景切换与模型更新，**不回写任何控制状态**。
- 实验产生的读数（readouts）是**单向显示数据**：只能被 UI 读取展示，绝不参与控制流，杜绝 UI↔3D 循环依赖。
- 重置按钮由 UI 侧做 300ms 补间，逐帧把中间值写入 `store.params`，与「不 debounce、rAF 合并」的渲染约定一致；引擎侧无需感知补间。
- 左面板 `320px + 1fr` Grid 与 `<768px` 底部抽屉断点，直接落 `styles/responsive.css`；token 表 1:1 落 `styles/tokens.css`。

## 6. 场景切换与 GPU 资源释放

1. 切换令牌（自增 id）防竞态：快速连点场景列表，旧切换未完成则作废其结果。
2. 切换时序（合成设计总裁「300ms 交叉淡入」与 3D 渲染师释放时序）：淡入 150ms → 构建新场景 → 淡出 150ms → 延迟 300ms 再释放旧场景。
3. 旧实验：暂停 step → `dispose()`（实验自己清内部引用）→ `disposeObject3D(root)` 遍历 `geometry.dispose / material.dispose / texture.dispose`（含材质上每个贴图槽位）→ `renderer.renderLists.dispose()`。
4. 新实验 `import()` → `build(ctx)` → 相机归位 → 恢复循环；`playing` 重置 true，`speed` 保留上次选择。

### 9.4 本轮定案口径
- 页面驱动参数必须走真实控件通路（`.param-block[data-pid] input` + `input` 事件），探针不直改 `store.params`（reset 后立即改 store 会丢 onParam）。

- v₁ 类「表对面板错」先怀疑缓存页：无头 Edge 长跑采样（真播放、每 300ms 取面板 DOM）三层（readouts/segments/DOM）比对定位。
