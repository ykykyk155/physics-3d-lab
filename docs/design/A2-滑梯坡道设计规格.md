## 0. 红线 —— 这些一个顶点都不许动

物理与视觉共用同一轮廓，动了就要重测 9 点摩擦标定：

- 几何来源 `docs/app/exp/mechanics.js:260-267` `_geometry()`：坡顶 T=(Tx, H)，直线坡 → R=0.3 圆弧 → B=(XF0, 0)，切线连续。
- 常量 `docs/app/exp/mechanics.js:396`：`BL=7.0, XF0=-1.2, RL=2.0`；`H = this.p.height`（**用户参数 0.05~0.5，默认 0.35**，见 `docs/app/data/experiments.json:30`），`θ=atan(H/RL)`（默认≈9.93°）。
- 视觉楔体 `docs/app/exp/mechanics.js:491-497`：ExtrudeGeometry 轮廓顶边 = 直线坡+圆弧，底边 y=-0.06，depth 0.44（z ±0.22），`bevelEnabled:false`。**轮廓顶点、挤出深度全部保持原样**，只换材质。
- 物理 triMesh `docs/app/exp/mechanics.js:297-302`（半宽 W=0.22、friction 0）、摩擦平面 `:308-311`、小车刚体 `:317-322`、标定 `k(μ)=0.945μ−0.19μ²` `:279-281`：**一行不改**。
- 五条水平轨道条、标记条、图例、「无阻力 → 循环往复」标签：不动。
- **不加任何碰撞体**——全部新件纯视觉。
- 全部新 mesh `castShadow=false; receiveShadow=false`（全站禁阴影，前后关系靠明度分层+轮廓+相切）。
- 新件全部进 `buildTracks()` 的 `isSel` 分支（`docs/app/exp/mechanics.js:487-506`），挂 `tracksG`，`userData.noFit=true`（相机取景不变）；现有 traverse dispose 自动清理，切材料/切高度重建无残留。
- **所有尺寸由 `g=this._geometry()` 与 `H=this.H_ramp` 推导，禁止硬编码 0.35**（高度是用户可调参数）。

## 1. 造型概念：「琥珀滑道 + 蓝扶栏」

一眼可认的儿童滑梯：暖琥珀塑料滑道（力学识别色）+ 蓝色侧板与圆润包边（主色族）+ 深灰蓝起滑平台/台阶（面板色族）。圆润安全感来自顶部包边圆管与护栏圆角，**不是**改滑道轮廓。

**真实比例基准（这是桌面教具，不是游乐设施；一切以小车为参照）**：

| 参照 | 实际尺寸 | 相对小车 |
| --- | --- | --- |
| 小车 | 长 0.52 / 宽 0.36 / 轮径 0.18 / 高≈0.26 m | 1 |
| 滑道内宽 | 0.44 m（楔体挤出深度，mechanics.js:496） | **1.22× 车宽**——车几乎填满滑道，轮缘离侧板仅 6mm |
| 侧板高 | 0.13 m | 0.72× 轮径，低于车侧栏顶，车身明显高出侧板 |
| 包边圆管 | 半径 0.024（管径 4.8cm） | 手指粗，绝非手臂粗 |
| 护栏管 | 柱 r0.02 / 杆 r0.018 | 细管 |
| 坡高（默认） | 0.35 m | 1.35× 车高；坡角≈10°，水平投影 2m = 3.8× 车长 |
| 平台 | 0.45 × 0.44 m | 比车 footprint 略小 |
| 整器总高（含护栏） | ≈0.56 m | 2.2× 车高 |

注意：A2 滑道宽是 **0.44m**（不是 0.86m——那是 A1 的板宽）；车宽 0.36m，所以滑道只比车宽一点点，这正是「真实教学仪器」的比例。

配色（3D 材质走 `docs/app/exp/common.js:15-27` COLORS 单一来源；复用已有键，新值在 COLORS 加键并注释对应 CSS 变量）：

| 部件 | 色值 | 来源 |
| --- | --- | --- |
| 滑道面 / 楔体 / 各处包边条 | #F59E0B | `COLORS.mechanics`（已有） |
| 两侧挡板 | #3B82F6 | `COLORS.primary`（已有） |
| 顶部包边圆管 / 平台护栏 | #60A5FA | COLORS 新键 `slideRail`（= 定稿palette --color-primary-hover，:root 暂未设该变量） |
| 起滑平台 | #323F5C | COLORS 新键 `slideDeck`（= :root --color-surface，index.html:36） |
| 台阶 | #3C4A6B | COLORS 新键 `slideStep`（= :root --color-surface-hover，index.html:37） |

材质：滑道 roughness 0.45 / metalness 0（模塑塑料）；侧板 0.5；包边/护栏 0.35~0.4（微亮抓光）；平台 0.8；台阶 0.85。

## 2. 结构件清单（z 均相对所选轨道中心；默认 h=0.35 时 Tx≈-3.23）

小车实测包络（`docs/app/exp/props.js:89-122`，A2 用 `cart({len:0.52, wid:0.36, wheelR:0.09})`，见 mechanics.js:223）：
- 车体半长 0.26；侧栏外缘 z ±0.18；**轮子最外缘 z ±0.219**（torus 中心 ±0.192 + 管半径 0.027）；
- 车体侧栏顶 ≈ 面上 0.1975；释放时后轮底 = H + 0.156·sinθ（h=0.05 时也有 H+0.004）。

### ① 滑道本体（现有楔体，仅换材质）
几何不变；`MATS.woodLight()` → 琥珀塑料 #F59E0B。

### ② 两侧挡板 ×2（新）
- 轮廓：与滑面同一 profile（T→B 直线+圆弧）向上偏移 0.13 闭合为带状，ExtrudeGeometry depth 0.05。
- 位置：内侧面 z=±0.225、外侧面 ±0.275。**轮外缘 0.219 → 单侧 6mm 间隙，全程不穿模**。
- 高：面上 0.13（低于车侧栏顶 0.1975，车身始终可见）。
- 终点：在 B=(XF0,0) 齐切，**不伸入水平段**。
- 材质 #3B82F6。

### ③ 顶部包边圆管 ×2（新，滑梯的「圆润安全边」）
- TubeGeometry 沿 profile 上移 0.13（侧板顶边），半径 0.024，中心 z=±0.25；B 端加 SphereGeometry(0.024) 圆头。
- 内缘 0.25−0.024=0.226 > 0.219 ✓。材质 #60A5FA。

### ④ 起滑平台（新）
- box 0.45(x)×0.05(y)×0.44(z)，顶面 y=H，x∈[Tx−0.45, Tx]，z ±0.22。材质 #323F5C。
- 前缘琥珀包边条 box 0.02×0.012×0.44 @ (Tx−0.01, H+0.006)。
- 穿模核验：释放位车后轮底 = H+0.156·sinθ > H（全高度域成立，最小间隙 4mm@h=0.05）；车尾 x≈Tx−0.256 悬于平台上方，不接触 ✓。

### ⑤ 平台护栏（U 形，开口朝滑道，新）
- `railH = clamp(0.6·H, 0.12, 0.26)`（随高度缩放，矮坡不显突兀）。
- 4 立柱 cyl r0.02 h=railH：(Tx−0.45, ±0.25) 与 (Tx−0.02, ±0.25)，底 y=H。
- 2 侧横杆 cyl r0.018 沿 x（Tx−0.45 → Tx−0.02），y=H+railH，z ±0.25；1 后横杆沿 z @ x=Tx−0.45。
- **前方无横杆**（小车出口）；立柱 z ±0.25 vs 轮外缘 0.219 → 31mm 间隙 ✓。
- 材质 #60A5FA。

### ⑥ 背后台阶 ×3（新）
- tread 0.16、宽 0.44（z ±0.22）；第 i 级（i=1..3）顶面 y=i·H/3，x∈[Tx−0.45−(4−i)·0.16, Tx−0.45−(3−i)·0.16]，实体盒从 y=−0.06 叠到顶面。
- 材质 #3C4A6B；每级前缘包边条 box 0.015×0.012×0.44，#F59E0B。
- 总后伸 0.48：默认 h 后台阶尾端 ≈-4.16，在底座（x −5.5..5.5）内 ✓。

### 合并 draw call
两侧板合 1、两包边+两圆头合 1、4 柱+3 杆合 1、3 台阶合 1、全部琥珀包边条合 1 → 约 +5 draw call（用现有 `mergeByMaterial`）。

## 3. 验收清单（3D渲染师自检 + CEO 复核）

- [ ] 9 点摩擦标定探针（0.02~0.7）全 ≤5%——几何未动，应原样通过。
- [ ] h=0.05 / 0.2 / 0.35 / 0.5 × 5 材料全程走查：车壳/轮子/侧栏与侧板/包边/平台/护栏/台阶零穿插（重点：轮外缘 0.219 vs 侧板内面 0.225；后轮底 vs 平台顶）。
- [ ] 理想光滑循环：瞬移回坡顶瞬间与护栏/平台零穿插；冰面末端刹停、三档正常停住行为不变。
- [ ] 坡脚圆弧接缝不弹跳、不离轨、不突然掉速（原验收项保留）。
- [ ] 新件全部无阴影；相机取景、图例、标记条不变。
- [ ] 切材料/切高度后重建无残留网格。
