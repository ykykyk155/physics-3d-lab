## 2. 电路图硬性规范

- 全部导线在 z≈0 同一竖直平面，正面视角可见；横平竖直（直角折线），圆角半径统一，线宽统一（fatLine 3）。
- 元件必须 **inline 坐在导线路径上**，导线从元件接线柱进、从另一柱出：
  - 串联：单一闭合矩形回路。电池组在底边，闸刀开关在底边（或顶边），L1、L2 在顶边。
  - 并联：干路（电池组 + 开关在底边）+ 两条支路（L1 上支路、L2 下支路），分支节点画实心圆点。
- 不出现断头线、不出现穿过元件内部的线、不出现元件悬空。
- 接线柱用现有黄铜材质（MATS.brass），每个接点可见。
- 全站规则：不开阴影（shadowMap.enabled=false），前后关系用明度分层/轮廓表达。
- 标签精简：

## 3. 仪表与换位（核心）

### 3.1 槽位定义

| 模式 | 电流槽（串入式） | 电压槽（跨接式） |
|---|---|---|
| 串联 | A（L1 前）、B（L1-L2 间）、C（L2 后） | L1、L2、batt（电源两端） |
| 并联 | a（干路）、b（L1 支路）、c（L2 支路） | L1、L2、batt |

### 3.2 安装形态

- **电流槽 = 串入式**：该处导线真实断开一个缺口，表体横置在缺口里（表盘朝 +z），两个接线柱分别用短引线接到缺口左端、右端两个**不同**接点。不允许两根表笔收到同一个点。
- **电压槽 = 跨接式**：表体放在被测元件正上方（约 +0.8 高）或正下方，两个接线柱用两根引线分别接到元件左端、右端两个**不同**接点。
- 两表都可放到任何槽（这正是「换位置」）：表移动到该槽、按该槽形态接线；表类型与槽类型不符即**误接**：
  - 电压表放电流槽 → toast「错误：电压表应与被测元件并联，不能串联进电路！」+ 导线闪烁；
  - 电流表放电压槽 → toast「错误：电流表应串联接入被测电路，不能并联在元件两端！」+ 灯泡暗一下；
  - 误接时该表读数显示 `—`。
- **交换**：若目标槽已被另一只表占用，则两只表互换槽位（直接换位置）。
- **默认状态**：串联 ammeter→A、voltmeter→L1；并联 ammeter→a、voltmeter→L1。默认两表都正确接入、都有读数。
- 切换模式后自动回默认槽位；旧测量点集按模式清空。

### 3.3 交互

- 点表身 → 选中（青环沿用）。
- 点槽位（导线上的接线点/元件）→ 选中表移动到该槽。
- `raycaster` 拾取沿用现有 `#viewport` pointerdown/up + 7px 阈值框架。

### 6.2 记录语义

- 「记录数据」记录**当前电压表读数 x** 与**电流表读数 y**；
- 只有开关闭合、两只表都正确接入（无 error）且读数为有限数时才允许记录；否则 toast「请先闭合开关并正确接入两只表」；
- 表格行：序号 / x.toFixed(2) / y.toFixed(3)；最新在下；
- 描点图：x 轴 U(V)、y 轴 I(A)，网格、散点（--color-primary）、≥2 点按 x 排序连线；轴范围按数据自适应（从 0 开始，至少 U:0~7 / I:0~0.7）；无数据时画空坐标轴 + 提示「记录 2 组以上数据后自动描点」；
- 「清空」清空表格 + 图；模式切换清空；底部「重置」也清空。

## 11. 验收（探针条目）

1. 默认串联：两表读数 0.10A / 1.00V，无 `—`；顶栏含「R总=30.0Ω」。
2. 电压改 6V：0.20A / 2.00V。
3. `toggleSwitch()` → 断开：电流表 0、电压表跨 L1 0；再 `toggleSwitch()` 恢复。
4. `placeMeter('amp','B')`、`('amp','C')` → 0.10A；leadEnds 两点距离 > 0.3。
5. `placeMeter('vol','L2')` → 2.00V；`('vol','batt')` → 3.00V。
6. 误接：`placeMeter('vol','A')` → toast 含「电压表应与被测元件并联」+ 读数 `—`；`placeMeter('amp','L1')` → toast 含「电流表应串联接入被测电路」+ 读数 `—`。
7. 并联模式：默认 0.45A / 3.00V；a/b/c 三槽 0.45/0.30/0.15A。
8. 记录：闭合正确接线，改电压 1.5/3/4.5/6 各点一次「记录数据」→ 表格 4 行、records 4 条、canvas 有像素；「清空」→ 0 行。
9. 结论：串测齐 A/B/C → 结论卡含「I_A = I_B = I_C」；并测齐 a/b/c → 含「I = I1 + I2」。
10. 0 pageerror / 0 console.error；ui-probe 全量回归通过；`renderer.shadowMap.enabled === false`。
11. 视觉三联图（串联默认 / 并联默认 / 记录+描点或误接）过目：无悬空元件、无单表笔线、标签不重叠、电路横平竖直。
