## 1. 目标
参考站 wuli.wkepu.com/10.html「探究影响浮力大小的因素」，修掉 A5 两个物理不自洽点，并补出教材必考观察链：

1. **浮沉自洽**：现在「浸没深度」是手动设定，ρobj 调成 0.5（比水轻）却只浸 27% 会显示「下沉」——真实物理里轻的应该漂着（ρ_eff < ρL → 自动漂浮，浸没比例 = ρ_eff/ρL）。
2. **完全浸没后示数恒定**：现在滑块 0~30cm 全映射到 0~100% 浸没，没有「完全浸没后再下潜、示数不变」的观察区间。改成滑块语义 =「下潜深度（物块底部在液面下的距离）」，物块边长 side 处即全浸，超过 side 后 F浮/示数恒定。

## 2. 物理模型（重写 recompute，公式为准）

输入参数不变，只改语义：
- `volume V`（cm³，20~500，默认 200）→ `side = cbrt(V)`（边长 cm，模型统一按 cm 计算）
- `rhoObj ρ物`（g/cm³，0.4~8.0，默认 0.9）
- `rhoLiquid ρ液`（g/cm³，0.8~1.3，默认 1.0）
- `submerge` **label 改为「下潜深度」**（id 保持 submerge 不动，cm，0~30，默认 5）→ 含义 = 物块底部在液面下距离 diveDepth
- `hollow` 实心/空心（ρ_eff 乘 0.45，现有逻辑不变）
- `ballast` 潜水艇水舱注水量（ρ_eff 乘 1 + ballast/100×0.8，现有逻辑不变）

有效密度：`ρ_eff = ρobj × (hollow ? 0.45 : 1) × (1 + ballast/100 × 0.8)`

浮沉判定（ε = 0.02 g/cm³）：
- `ρ_eff > ρL + ε` → **下沉**：浸没深度 = min(diveDepth, side)，浸没比例 = min(diveDepth, side)/side
- `|ρ_eff − ρL| ≤ ε` → **悬浮**：浸没比例 = 100%（完全浸没、停在滑块设定深度任意位置），示数 = 0
- `ρ_eff < ρL − ε` → **漂浮**：浸没比例 = ρ_eff/ρL（<1），示数 = 0，滑块无效

物理量（统一 SI，g=9.8）：
- `Vsub = V × 浸没比例`（m³）
- `G = ρ_eff (kg/m³) × V × g`
- `Fb = ρL (kg/m³) × Vsub × g`；完全浸没后 Vsub = V，Fb = ρL·V·g **恒定**
- `示数 read = max(0, G − Fb)`（漂浮/悬浮恒 0，绝不为负）

## 4. 视觉与交互（3D 场景）

- **溢水杯/接水桶/排水**：全部保留；接水桶水位仍随浸没比例涨（漂浮时浸没比例 = ρ_eff/ρL 同样排水）。
- **物块三姿态**（display 边长 disp 沿用现有放大 clamp）：
  - 下沉：块底在液面下 = diveDepth（显示换算同比例），块顶露出，绳子拉紧；diveDepth ≥ 缸内可用深度时视觉钳在缸底上方（约 y≥0.1），读数照算不钳。
  - 悬浮：块完全浸没、停在滑块设定深度，绳子松垂/拉直均可但示数恒 0。
  - 漂浮：块自动浮到液面，浸没部分 = 浸没比例 × disp 在水下、露出部分在水上；绳子从挂钩垂下到块顶（示数 0）。
- **液色随 ρL 渐变**：复用 mechanics.js A4 的 `liquidColor(rho)`（相同锚点 酒精/水/盐水/硫酸铜），A5 的 water 材质颜色跟随，与 A4 视觉一致。
- **滑块失效提示**：当处于漂浮（ρ_eff < ρL − ε）时，「下潜深度」滑块参数块弱化（加低透明度/置灰样式 + 行内小字「物体比液体轻 → 自动漂浮，无需下潜」）；悬浮/下沉时滑块正常可用。实现方式自行选择（A5 场景切换后按当前状态给该 param-block 加/去 .inactive 类），但要保证切换参数后状态刷新。

## 5. 读数与状态标签

readouts() 保持 5 项、顺序不变，但「浮沉状态」按新判定输出四种：
- `下沉中`（ρ_eff > ρL 且 diveDepth < side）
- `完全浸没 · 示数恒定`（ρ_eff > ρL 且 diveDepth ≥ side）
- `悬浮`（|ρ_eff − ρL| ≤ ε）
- `漂浮`（ρ_eff < ρL − ε）

场景大标签 lRead 保持「状态 · 浸没 X% · 示数 Y.NN N」统一格式（例：`漂浮 · 浸没 60% · 示数 0.00 N`、`完全浸没 · 示数恒定 · 示数 0.52 N`）。浸没比例 = 漂浮时 ρ_eff/ρL ×100、其余 min(diveDepth,side)/side ×100、悬浮 100%。

## 6. 教材三连观察路径（验收演示，逐个断言可跑）

1. **示数随浸入单调下降 → 完全浸没后恒定**：切「铝」(2.7)+水：拖下潜 0→side 段，示数 = G−ρL·g·Vsub 单调下降；拖过 side（如 6→30cm），示数恒定 ≈ G−ρL·g·V。
2. **轻物漂浮**：切「木」(0.6)+水：浸没比例 = 60%，示数 0，滑块置灰提示，露出 40%。
3. **液体密度越大浮力越大/浮得越高**：木 0.6 + 盐水(1.1)：浸没比例 = 0.6/1.1 ≈ 55%（更浅）；+ 酒精(0.8)：0.6/0.8 = 75%。
4. **悬浮**：实心 ρobj=1.0 + 水：悬浮、浸没 100%、示数 0、停在设定深度。
5. **潜水艇配重**：塑料 0.9 + 水 → 漂浮；ballast 调 50% → ρ_eff=0.9×1.4=1.26 > 1.0 → 下沉，示数出现，滑块生效。
