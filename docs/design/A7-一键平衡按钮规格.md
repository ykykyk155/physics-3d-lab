# A7 杠杆平衡：一键平衡按钮（双按钮）规格

> 状态：定稿（CEO 2026-11-22）。用户拍板「两个按钮，一个是以左边为基准，另一个以右边为基准」。
> 实施分工：外壳/渲染层（index.html + experiments.json 元数据）→ 前端工程师；实验实现（exp/mechanics.js 的 A7）→ 3D渲染师。

## 1. 需求

A7 参数面板（动力 F1 / 动力臂 L1 / 阻力 F2 / 阻力臂 L2 四个滑块）下方加一排两个按钮：

1. **以左边为基准**：保持 F1、L1 不变，自动调整 F2、L2 使 F1·L1 = F2·L2（力矩相等、杠杆水平平衡）。
2. **以右边为基准**：保持 F2、L2 不变，自动调整 F1、L1 使 F1·L1 = F2·L2。

点击按钮后：杠杆立即平衡（`duration` 变 0、时间条置灰、状态标签显示「平衡（保持水平）」、`t` 归零），滑块数值同步更新，与手动拖动滑块结果完全一致。

## 2. 配平算法（实验实现内，确定性）

- 网格（与 experiments.json 的 A7 滑块定义一致，改动 JSON 时必须同步此网格）：
  - F 网格：0.5 → 5.0，步进 0.5（共 10 档：0.5, 1, 1.5, …, 5）
  - L 网格：1 → 10，步进 1（共 10 档：1, 2, …, 10）
- target = 基准侧力矩（以左为基准时 target = f1·l1；以右为基准时 target = f2·l2）。
- 在另一侧的 F×L 全部 100 个组合中挑选：
  1. 误差 `err = |f·l − target|` 最小者；
  2. 误差并列时，取与当前滑块值的曼哈顿距离 `|f − fCur| + |l − lCur|` 最小者；
  3. 仍并列时取先枚举到者（f 从小到大、l 从小到大）。
- 由于基准侧的 f、l 本身就在网格内（target = f1·l1 必可精确表示），误差最小解通常是 err = 0 的精确平衡；算法必须能 return 精确组合，不允许返回「误差还可再小」的非精确值。
- 结果确定性：同一参数组合点击按钮，两次结果逐位一致。

## 3. 实现位置与接口

### 3.1 实验实现（3D渲染师 · exp/mechanics.js · A7 对象内）

新增 `actions` 字段，外壳点击按钮时按 id 调用：

```js
actions: {
  'balance-left'() {   // 以左边为基准
    const target = this.p.f1 * this.p.l1;
    const [f2, l2] = pickBalance(this.p.f2, this.p.l2, target);
    this.ctx.ui.setParamValue('f2', f2);
    this.ctx.ui.setParamValue('l2', l2);
  },
  'balance-right'() {  // 以右边为基准
    const target = this.p.f2 * this.p.l2;
    const [f1, l1] = pickBalance(this.p.f1, this.p.l1, target);
    this.ctx.ui.setParamValue('f1', f1);
    this.ctx.ui.setParamValue('l1', l1);
  },
}
```

- `pickBalance(fCur, lCur, target)` 为 A7 内的网格枚举 helper，规则见第 2 节；网格常量写在 helper 旁并注释「与 experiments.json 的 A7 min/step 同步」。
- **必须走 `ctx.ui.setParamValue` 写回滑块**：它写入 `store.params` + 标记 pending + 刷新滑块 UI，经外壳 rAF 合并后触发 `onParam` → `recompute()` → `_render(0)`，读书/标签/时间条自动更新。禁止直接改 `this.p` 再手动调 recompute（会绕过滑块 UI 同步）。
- 不改动其余物理逻辑（刚体重建、铰链限位、TOL、duration 分支等全部保持现状）。

### 3.2 外壳渲染层（前端工程师 · index.html + experiments.json）

**experiments.json**：A7 条目（id 为 `"A7-lever"`）加：

```json
"actions": [
  { "id": "balance-left", "label": "以左边为基准", "desc": "保持 F1、L1 不变，自动调整 F2、L2 使力矩相等" },
  { "id": "balance-right", "label": "以右边为基准", "desc": "保持 F2、L2 不变，自动调整 F1、L1 使力矩相等" }
]
```

**index.html `renderParams`**：在参数块全部渲染之后（`forEach(p => …)` 之后、`renderReadouts()` 之前）追加：

```js
if(Array.isArray(meta.actions) && meta.actions.length){
  const aw = el('div', 'exp-actions');
  meta.actions.forEach(a => {
    const b = el('button', 'exp-action');
    b.type = 'button';
    b.dataset.action = a.id;
    b.textContent = a.label;
    if(a.desc) b.title = a.desc;
    b.addEventListener('click', () => {
      const exp = current && current.exp;
      const fn = exp && exp.actions && exp.actions[a.id];
      if(typeof fn === 'function'){ try{ fn.call(exp); }catch(e){ console.error('[action:'+a.id+']', e); toast('操作失败，详见控制台'); } }
      else toast(a.label + '：' + (a.desc || '当前实验暂未实现'));
    });
    aw.appendChild(b);
  });
  box.appendChild(aw);
}
```

（id 命名 `balance-left`/`balance-right` 与 exp.actions 的键一一对应，外壳只做「渲染 + 转发」，不含任何实验算法。）

## 4. 验收标准（CEO 复验，发布前）

1. A7 默认态（f1=2/l1=4/f2=4/l2=2，已平衡）：点任一按钮，参数不变或仍在网格内、`duration=0`、标签「平衡（保持水平）」。
2. 扰动后（如 f1=3.5、l1=7，或 f2=0.5、l2=3）：点「以左边为基准」，右侧滑块同步更新、F1·L1 与 F2·L2 读数码（双数值条）相等、梁水平静止、时间条置灰；点「以右边为基准」对称。
3. 任意参数组合下点按钮：`net=0`（或网格内最小误差，无因浮点产生的 |net|>0.05 抖动）；滑块 UI 数值与 store.params 一致；无 console 报错。
4. 两个按钮同时存在、布局不溢出、对比度达标（深色主题、无阴影、不缩字号）。
5. 探针脚本 `docs/app/probe-a7-balance.mjs`（CEO 出，3D渲染师可先提供关键数值）全绿。
6. 发布：main + gh-pages 双分支，线上 curl 确认新代码生效。
