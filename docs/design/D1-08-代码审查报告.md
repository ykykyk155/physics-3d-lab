## 一、阻塞问题（必须修复）

### 1.1 串联 A/B 表槽的导线端点接反，默认视图即出现「一根线穿过表体」
位置：`docs/app/exp/electricity.js:429-436`（`buildCircuit()`）

现状：
```js
if (this._hasMeter('B')) {
  segs.push([[l2L, yT], [B.cx - 0.55, yT]]);
  segs.push([[B.cx + 0.55, yT], [l1R, yT]]);
} else segs.push([[l2L, yT], [l1R, yT]]);
if (this._hasMeter('A')) {
  segs.push([[l1L, yT], [A.cx - 0.55, yT]]);
  segs.push([[A.cx + 0.55, yT], [xL, yT], [xL, yB]]);
} else segs.push([[l1L, yT], [xL, yT], [xL, yB]]);
```
- B 槽：`B.cx=0.50`、`l2L=1.15`、`l1R=-0.15` ⇒ 实际画 `1.15→-0.05` 与 `1.05→-0.15`，两根线都从表体后方穿过槽口；正确应为 `1.15→1.05`（接 `B.cx+0.55`）与 `-0.05→-0.15`（接 `B.cx-0.55`）。
- A 槽：`A.cx=-1.45`、`l1L=-0.55`、`xL=-2.2` ⇒ 实际画 `-0.55→-2.0` 与 `-0.9→-2.2`，同样横穿槽口；正确应为 `-0.55→-0.9`（接 `A.cx+0.55`）与 `-2.0→-2.2`（接 `A.cx-0.55`）。
- 默认 `ampSlot='A'`，所以打开串联默认态就触发：粗红线从 `x=-2.2` 连续到 `-0.55`，仪表像被导线旁路，正是用户反复强调的「不要像之前的连一根线」。
- C 槽 `:423-425` 的写法正确，可作对照。
- 复现证据：`node docs/app/probe-d1-wirecheck.mjs`（审查辅助脚本，读取 `e.wires` 的 `instanceStart` 线段）输出 `slot A (ampSlot=A) crossingSegments=2 [[-0.550,2.650]→[-2.000,2.650]] [[-0.900,2.650]→[-2.080,2.650]]`，即两根导线跨越 A 槽口 `[-2.0,-0.9]`。

### 1.2 `placeMeter()` 换槽后不重建电路，导线断口不跟随仪表
位置：`docs/app/exp/electricity.js:197-216`

`placeMeter()` 只更新 `ampSlot`/`volSlot`、读数、标签与 `_layoutMeters()`，没有调用 `buildCircuit()`；而导线断口是在 `buildCircuit()` 里按 `_hasMeter(slot)` 生成的。结果是：
- 默认态断口只在 A；把电流表换到 B/C 后，A 的断口仍在、B/C 仍是一条连续导线，仪表看起来悬在导线上。
- 与规格 §3「两表可任意换槽」「电流槽=串入式导线缺口两接线端」不符，也让「电表可换位置」只剩读数变化、没有电路形态变化。
- 复现证据：同一辅助脚本 `placeMeter('amp','B')` 后输出 `slot B (ampSlot=B) crossingSegments=1 [[1.150,2.650]→[-0.150,2.650]]`；`placeMeter('amp','C')` 后仍是默认 A 断口几何的 `2.83→1.55` 连续段——说明换槽没有触发 `buildCircuit()`。

建议：`placeMeter()` 更新槽位后先 `this.buildCircuit()`（重算断口/接线柱/空槽触点），再 `_refreshMeters()/_syncNeedles()/_renderValLabels()/_layoutMeters()/_refreshConcl()`。

## 二、测试缺口（中优先级）

`docs/app/probe-d1-redo.mjs` 57 项未覆盖以下确定性行为，建议补回归断言：

1. **R1/R2 参数变化**：只改了 `voltage`/`mode`/`switch`，未测 `r1`/`r2` 改变后 `I=U/(R1+R2)`、分压/分流读数是否跟随（规格 §4）。
2. **误接时记录被拒**：只测了「开关断开」的记录拒绝（约 `probe-d1-redo.mjs:192`），未测两只表任一误接时 `recordSample()` 应返回 `{ok:false,msg:'请先闭合开关并正确接入两只表'}`。
3. **记录清空**：未测模式切换自动清空记录、底部「重置」清空记录（规格 §6.2）。
4. **槽口几何回归**：未断言「占用槽位的导线必须真实断开」——正因缺这条，1.1/1.2 才会漏过 57/57。建议增加 `getWireSegments()` 读取 `e.wires` 的 `instanceStart`（每段 6 个 float：x1,y1,z1,x2,y2,z2），断言任何 y≈yT 的段不得跨越占用槽的 `[cx-0.55, cx+0.55]`。

## 三、低优先级与说明

1. **硬编码色值**（`docs/app/exp/electricity.js:68/74/81-82/89/98/112-113`）与规格 §4「颜色沿用现有 COLORS/标签色，不新增硬编码色值」不一致；建议收敛到 `COLORS.electricity`/`MATS` 或补入共享色表。
2. **性能**：`buildCircuit()` 在每次 `recompute()`（任意参数变化，滑块拖动≈每帧）全量重建导线、30 实例电子、接线柱与节点；仅 `scene.remove()`，未 dispose `parts/points/junctions` 的几何/材质；`common.js:108` 的 `_lineMats` 每次 `fatLine()` 都 push，会持续累积。建议把结构重建限定在模式/槽位变化，参数变化只更新读数/亮度/标签。
3. **`syncDataRecord`**（`docs/app/index.html:1110-1135`）每 100ms 无条件重建 `#recTableBody.innerHTML`；只有图表用 `recSig` 防抖，建议表格也按签名跳过。
4. **说明（intentional deviation）**：规格 §2 原写「电压表读数标签在表体下方」，实现放在表体右侧（`electricity.js:271`，`bodyX+0.90, bodyY+0.06`），是视觉验收打回后为避免压灯泡光晕的调整；建议回写规格、明确为有意变更。
5. **说明**：`placeMeter()` 互换路径对另一只表 `_applySlotState(..., quiet=true)`（`electricity.js:206-207`），交换后被换入错槽的表不额外弹 toast；确认是否产品预期。
6. **术语**：`readouts()` 实现标签为 `电流 I`/`电流表 I_测`/`电压表 U_测`，规格 §4 为 `干路电流 I`/`电流表读数`/`电压表读数`，仅命名一致性，不阻塞。
