## 2. 数值口径（对齐参考站基准电阻制）

参考站材料基准阻值（1m、S）：铜 2 / 铁 4 / 康铜 6 / 镍铬 8 Ω。我们对齐：

- `R = ρ0 × (L/100) × (1/S) / strands × (1 + temp×0.002)`，其中 ρ0 = 材料基准值（Ω·mm²/m 名义）。
- 材料枚举值改为基准制（**名称不变，只改 value**）：
  - 镍铬 1.1 → **8**
  - 锰铜 0.44 → **6**（近似参考站康铜档）
  - 铁 0.1 → **4**
  - 铜 0.017 → **2**
- 默认（镍铬 8、L=50cm、S=1.0、strands=1、temp=20）：R = 8×0.5×1.04 = **4.16 Ω**，I = 6/4.16 = **1.44 A**（量程 0~3A 内，指针约半偏，好读）。
- 电源恒 **U = 6V**（与参考站一致，不暴露为参数）。
- 电流表量程 **0~3A**：指针 frac = clamp(I/3, 0, 1)；（极端组合如铜+短+粗+多根 I 超大时指针满偏，读数标签仍显示真实数值并前置「⚠」）。

## 4. 待测导体（实物化，外观随三因素变）

- 位置：顶边 y=2.9，center x=0.9，水平放置（rotation.z = π/2 的圆柱）。
- **长度**：L 10~100cm → 3D 长 1.0~3.0（`len = 0.8 + L/100*2.2`，L=50 → 1.9；L=100 → 3.0；L=10 → 1.02），左端随长度变化、右端固定在 x=0.9+len/2 处左移？——固定 center=0.9，两端随长度伸缩（左端 0.9−len/2、右端 0.9+len/2），右端 ≤ 2.4 不碰右竖边（2.6）。
- **粗细**：S 0.5~4.0mm² → 半径 0.035~0.10（`r = 0.025 + Math.sqrt(S/4)*0.075`，S=1 → 0.0625、S=4 → 0.10、S=0.5 → 0.0515）。
- **颜色随材料**（参考站色系，MeshStandardMaterial 自定义）：
  - 镍铬 8 → 银白 `#d8dde4`
  - 锰铜 6 → 金黄 `#d4a04a`（近似参考站康铜 #d4b04a）
  - 铁 4 → 蓝灰 `#5a6a7a`
  - 铜 2 → 铜红 `#d4785e`
- **并联根数 strands**：导体由 `strands` 根并排细圆柱组成（间距 0.16），每根半径 = 上面 r 公式×0.75；strands=1 单根（等效总截面积不变，R÷strands 体现并联）。
- **两端接线柱**：黄铜柱（`cyl + MATS.brass()`，高约 0.18），导线从柱顶水平接入（导体在顶边，接线柱竖直向下接导线端点）。
- 温度不改变导体外观（只影响读数）。

## 12. 验收（探针条目，CEO 写 probe-d2-redo.mjs）

1. 默认（镍铬/50cm/1.0/1根/20℃）：R≈4.16（±0.02），I≈1.44（±0.01），readouts 6 项含 I。

7. strands=4 → R ÷4（1.04）、I×4。
8. 3D 断言：场景中 battery/knifeSwitch/ammeter/bulb/导体 5 类元件存在；`renderer.shadowMap.enabled === false`；0 pageerror / 0 console.error。
