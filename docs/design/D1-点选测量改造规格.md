# D1 串联与并联电路 · 点选测量型改造规格

> 状态：定稿 · 依据：用户 m00429「电学08先研究一下这个网站是怎么实现的」+ m00465 外出授权（选择题一律按 CEO 推荐执行）
> 参考站：docs/benchmark/wuli/26.html（电流）、28.html（电压）——它们都是「点选测量型」探究实验：点击测量点/元件 → 表笔自动接入 → 读数进数据卡 → 测齐自动弹结论。

## 1. 目标

把 D1（series-parallel）从「演示型」升级为「3D 点选测量型」，对齐参考站探究流程，同时**保留现有 3D 实物（电池组/灯泡×2/闸刀开关）、粒子动画、参数滑块**。

满足附录 A 的 phenomenon 全部点：
- 导线内电子流实时流动（已有，保留）；
- 断开一处 → 串联全灭、并联只灭一支（已有，保留）；
- **两只电表读数实时验证规律**（新增：一只电流表 + 一只电压表，点选接入）；
- **电流表误并、电压表误串 → 异常并弹提示**（新增）；
- 测齐关键点自动弹结论（新增）。

## 2. 交互总览

1. 场景中放置**两只表**：左侧电流表（已有 ammeter 组件，位置可变）、右侧电压表（需在 props.js 新增 `voltmeter` 组件，表盘标注 V）。
2. 场景导线与元件上放置**测量触点小球**（发光小圆球，hover 放大 + 光标 pointer，点击判定为「表笔接入」）。
3. 点击触点/元件 → 对应表自动移动到被测位置、拉出表笔引线、读数实时显示在表盘和右侧统计面板。
4. 测齐一组关键点 → 场景弹绿色结论卡（复用 mkLabel 或自建 CSS2D 卡，走 var(--color-*) 变量，不硬编码颜色）。
5. 误接（电流表点元件、电压表点导线触点）→ toast 警示 + 电路异常表现；断路时点测量点 → toast 警示。

## 3. 测量点与读数表

触点 id 与语义（坐标系由实现者按电路拓扑放置，要求射线可命中、不被器材遮挡、hover 明显）：

| 触点 | 位置语义 | 电流表读数（闭合） | 电压表读数（闭合） |
|---|---|---|---|
| 串联 A | 电池正极出线 → L1 前 | I（=干路电流） | L1 两端电压 U·R1/(R1+R2) |
| 串联 B | L1 与 L2 之间 | I | L2 两端电压 U·R2/(R1+R2) |
| 串联 C | L2 后 → 回电池负极前 | I | 电池两端电压 = U |
| 并联 a | 干路（电池正极出线） | I（=I1+I2） | L1 两端电压 = U |
| 并联 b | L1 支路 | I1 = U/R1 | L2 两端电压 = U |
| 并联 c | L2 支路 | I2 = U/R2 | 电池两端电压 = U |

电流表**只能点导线触点**（A/B/C、a/b/c）；电压表**只能点元件**（L1 灯泡、L2 灯泡、电池）。
点其余目标视为误接（见 §5）。

**断路（switch=off）读数**：
- 电流表：所有触点读数 = 0；
- 电压表：点**电池** = U（经典考点：断路时电压表直接接电源两极读电源电压）；点 L1/L2 = 0；
- 点任何触点都 toast「电路已断开，请先闭合开关」。

## 4. 读数（readouts）

保持 3~6 项，随测量状态实时变化：

```js
readouts() {
  return [
    rd('电源电压 U', this.p.voltage || 0, 'V'),
    rd('总电阻 R', this.Req, 'Ω', 1),
    rd('干路电流 I', this.I, 'A', 2),
    rd('电流表 I_测', this.ampReading, 'A', 2),   // 未测时显示 '—'，测后显示所在段电流
    rd('电压表 U_测', this.volReading, 'V', 2),   // 未测时显示 '—'
    rd('开关', this.p.switch === 'off' ? '断开' : '闭合', ''),
  ];
}
```

「连接方式」保留在场景顶栏标签（已有 lbl），不再占 readouts 位。

## 5. 误接与异常提示

| 操作 | 表现 |
|---|---|
| 电流表点元件（灯泡/电池） | toast「错误：电流表应串联接入被测电路，不能并联在元件两端！」；该元件灯灭/变暗一瞬示意异常，读数保持 '—' |
| 电压表点导线触点 | toast「错误：电压表应与被测元件并联，不能串联进电路！」；电路闪烁示意异常，读数保持 '—' |
| 断路时点任何触点 | toast「电路已断开，请先闭合开关」 |
| 电流表点触点（正确） | 表移动到触点段、拉引线、读数显示该段电流 |
| 电压表点元件（正确） | 表移动到元件旁、两根引线接元件两端、读数显示元件电压 |

## 6. 自动结论（测齐判定）

- 串联：电流表测齐 **A、B、C** 三点 → 结论「串联电路：I 处处相等（I_A = I_B = I_C）」；电压表再测齐 L1、L2、电池 → 追加「且 U = U1 + U2（串联分压）」。
- 并联：电流表测齐 **a、b、c** → 结论「并联电路：干路电流等于各支路之和（I = I1 + I2）」；电压表测 L1、L2、电池（任意两点即等同） → 追加「且各支路电压相等 = 电源电压」。
- 结论呈现：场景内绿色大字卡（ttl 5s + 常驻可手动关闭），文字必须与当前读数一致（数字随参数实时更新，不能写死）。
- 切换 mode/参数后，测齐状态保留（已测点仍算已测），结论文字随新读数刷新。

## 7. 技术改造点

### @3D渲染师（docs/app/exp/electricity.js 的 D1 + docs/app/exp/props.js）
1. props.js 新增 `voltmeter(opts)` 组件（与 ammeter 同风格，表盘标 V，红黑接线柱）。
2. D1.build：场景加电压表；给导线段/元件加**触点小球**（发光、可 hover、userData 标记类型 `pickTarget:{kind:'amp-point'|'vol-point', id:'A'|'B'|'C'|'a'|'b'|'c'}`）；电流表/电压表改为可移动（放 Group 内），内置表笔引线组（fatLine）。
3. 交互自建：`const vp = document.getElementById('viewport')`（ctx 已给 scene/camera/renderer/controls）→ vp 上挂 pointerdown/pointermove：
   - **点击判定**：pointerdown 记录 x/y，pointerup 位移 < 6px 才算点击（否则交给 OrbitControls 拖拽）；
   - pointermove raycast 触点 hover：命中触点放大 + canvas 光标 pointer；离开恢复；
   - 命中后用 `ctx.scene` 的 Raycaster 区分触点与元件（Raycaster 自建，`new THREE.Raycaster()`，从 `ctx.camera` + 指针 NDC）。
4. 表接入视觉效果：点击后把对应表（Group）tween 移到目标点（可瞬移，300ms 补间更佳）、重建表笔引线（电流表两根串入触点段两端、电压表两根跨接元件两端）、表盘指针按读数摆（复用 setMeterNeedle）。
5. 读数：`this.ampReading / this.volReading`（'—' 或数值），recompute() 里随 I/U/R 与所选点刷新；发射到 ctx.emitReadout 维持现有 cur。
6. 自动结论：测齐判定 + 结论卡（mkLabel 大字，颜色走 `var(--color-ok)` 或设计总裁给值；不硬编码）。
7. 误接/断路：toast 弹窗（`document` 上无现成 toast 接口给实验——**外壳由前端工程师在 ctx 加一个 `ctx.toast(msg)` 转发全局 toast()**，实验只调 ctx.toast）。
8. 探针可测性：触点小球挂稳定的 id/name（如 `d1-point-A`），探针用 DOM 事件 + raycast 或直接调内部方法。

## 8. 验收标准

探针 probe-d1-measure.mjs（本地 + 线上各一份，真实 DOM 交互）：
1. 串联闭合：电流表点 A/B/C 三处读数均 = U/(R1+R2)（容差 <0.001），且文案结论「处处相等」出现；
2. 串联：电压表点 L1 = U·R1/(R1+R2)、点 L2 = U·R2/(R1+R2)、点电池 = U（各容差 <0.001），结论「U=U1+U2」出现；
3. 并联：点 a/d 干路 = U·(R1+R2)/(R1·R2)，点 b = U/R1、点 c = U/R2；结论「I1+I2」与「各支路电压相等」出现；
4. 误并：电流表点灯泡 → toast 出现「电流表」且读数保持 '—'；
5. 误串：电压表点导线触点 → toast 出现「电压表」且读数 '—'；
6. 断路：电流表点任何触点 toast「开关」、读数 0；电压表点电池 = U、点灯泡 = 0；
7. 未测时 readouts 里 I_测/U_测 显示 '—' 不为 NaN/空字符串；总项数 ≤6；
8. 滑块改动后读数与结论数字同步刷新（先测 A→改 r1→A 读数跟随新 Req）；
9. 0 pageerror / console.error；ui-probe 全量回归 0 新增失败（顺带跑）。
