# 基准笔记 · yanwulab（演物实验室）+ wuli.wkepu（初中物理仿真实验库）

> 调研人：前端工程师 · 供 CEO 汇总决策表（与 xiaobinlaoshi-notes.md、nobook-notes.md 并列）
> 方法：yanwulab 抓 /labs 目录、/api/curriculum、/api/labs/{slug} 与 motion3d 运行时源码；wkepu 抓首页 index2.5.js（内嵌 32 实验完整目录）、26 号实验页源码与 26.js 运行时、common2.0.js 公共壳。原始抓取件在 docs/benchmark/_yanwu-*.{json,html}、_wkepu-*.{html,js}。

## 一句话结论

- **yanwulab**：和我们同路线（纯前端 three.js + ES modules + 按实验动态加载），它的**教材节次→实验章节映射**和**数据表随实验生成**是我们直接缺的两块；三视角预设按钮、演示模式、安全条都是小成本补齐项。
- **wkepu**：2D Canvas 手绘路线（正好反衬我们 3D 路线，nobook 数据 3D 比 2D 多 79% 使用量），它最好的东西是**分步引导 overlay**（❓ 按钮带着学生一步步做实验）和 ℹ️ 实验说明弹窗——我们全空白、成本低。

## 诚实口径

- wkepu 是 2D Canvas 手绘器材（线条画灯泡/电表），非 3D 实物化；其价值在交互教学结构（引导/说明/目录），不在渲染。
- wkepu 的"知识专题/解题指导"两个栏目正文由 JS 动态加载，本次未抓到正文，"未见"≠没有。
- yanwulab 免费全解锁（vipOnly=0），没有 VIP/账号分层可对照；价格/商业模式无从记录。
- 两站的实验页都未做时间轴拖动/回放条——我们的 seek 时间条是独有强项。
- 抓取件为当日快照（2026-11-21），线上改版后以现场为准。

## 优先级建议（供决策表合并）

**一期候选（成本低、原料全有）**：① 分步引导 overlay（wkepu #14）；② 指导抽屉 = goal + 要点 + 说明弹窗合并（yanwulab #5 + wkepu #14，与 nobook「学案抽屉」同款）；③ 章节视图（yanwulab #1，与 nobook 同款）；④ 三视角预设 + 全屏（#3）；⑤ A1 数据表（#6）；⑥ 安全条（#10）。
**二期**：演示模式（#4/#15，字号变量化后顺手）、二维码分享（#16）、拖拽交互（#9）。
**不做**：搜索（#12）、防复制（#17）、账号/登录（用户已定：纯静态打开即用）。
**二期选题参考**：wkepu 缺口 12 个实验 + nobook 使用量排序（滑轮组 290.7k 优先）。
