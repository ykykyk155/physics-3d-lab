## 一、平台结构速览（观察事实）

1. **学段 × 教材组织**：URL 带学段与教材编号（/console/junior/1/），顶部「初中」下拉；左侧筛选树有**章节 / 知识点**两个页签（树内容由 JS 加载，未登录未展开）。
2. **教师端导航**：精品实验（公共库）/ 我的实验（私有课件，/console/coursewares）/ 新建实验（沙盒自建）/ 添加教师端至桌面 / 下载学生 APP / 登录注册。
3. **筛选与排序条**（精品实验库顶部，全部实抓确认）：
   - 资源类型：全部 / 探究实验 / 学案 / 互动课件
   - 排序：教学进度 / 使用最多 / 最新发布
   - 开关：新课标 / 仅看免费
   - 可收起的「实验专题推荐」运营位
4. **卡片**：缩略图 + 实验名 + 使用量（如「380.3k」）。详情页另有「N 人观看 / N 点赞 / 分享 / 去做实验 / 更多实验」。**未观察到收藏数**（可能在登录态内）。
5. **详情页 = 一份完整学案**（杠杆样例逐字结构）：实验操作视频 → 实验目的（课标原句）→ 实验原理 → 实验器材 → 实验步骤（编号 1~5）→ **数据记录表**（次数/动力F1/N/动力臂l1/m/阻力F2/N/阻力臂l2/m，空行待填）→ 实验结论 → 实验补充（教学提示：杠杆为何要水平平衡——力臂便于测量）。
6. **多端**：Windows/Mac 客户端下载 + 网页版 + 手机扫码体验 + 学生 APP；商业化为首月 VIP ¥9.9 的免费增值模式（价格页为壳，未验证档位）。
7. **测评是独立产品线**（NB物理实验测评，与实验库并列导航），内部需登录，未验证。
8. **同一知识点多资源**：平面镜成像有 2D 版（380.3k）与「3d平面镜成像」（679.4k）两条；杠杆有两条（186k / 138.1k）；「测量滑动摩擦力」有（一）（二）（三）；「弹力的有无」有（1）~（6）系列；另有**题型资源**：形杯问题 1~4（同液等高/异液等高/同液等质/异液等质）、固体压强叠加、规则柱体压强、压强/压力相同-水平切割。

## 二、借鉴点清单（它做了什么 → 我们可做什么 → 倾向）

### 1. 章节视图（教学进度排序）——【做，优先级最高】
- 它：章节树筛选 + 「教学进度」排序，教师按课本进度找实验。
- 我们：左侧页签按**学科模块**分（力学01–07/电学08–14/光学15–19/声学20–22/热学23–25），但 `docs/app/data/experiments.json` 里**每个实验已有 chapter 字段**（如「八上 第一章 第4节 速度的测量」），数据零新增。
- 落地：加一个「按课本章节」视图切换（八上/八下/九全 → 章 → 节），纯前端重新分组现有 25 条；模块视图保留。教师备课按进度走，学生复习按模块走，两种心智都照顾。
- 倾向：**做**。成本最低、价值最高的一条。知识点第二轴**不做**——25 个规模下双轴筛选是过度设计，章节轴足够。

### 2. 实验指导（学案结构进详情页）——【做】
- 它：每个实验自带目的/原理/器材/步骤/数据表/结论/补充七段学案 + 操作视频。
- 我们：JSON 已有 formula（原理）、params（器材与步骤的原料）、phenomenon（结论，且**已含破除迷思概念句**，如 A1「重的快」、A4「液体越重压强越大」）、chapter（课标定位）。内容一半已在库里，缺的是呈现。
- 落地：每个实验加可收起「实验指导」抽屉：目的（一句话）/原理（公式）/器材清单/步骤 3~5 条/结论/易错提醒。把「看动画」升级成「做实验」，直接服务中考实验操作考核场景。
- 倾向：**做**（文本部分一期）；数据记录表「记录当前读数」按钮（readouts 实时值一键进表、localStorage 存）缓做二期；操作视频不做（无视频产能，3D 场景本身即演示）。

### 3. 使用量 / 点赞 / 收藏——【不做】
- 它：卡片使用量（380.3k）、详情页观看/点赞，社会证明驱动选择。
- 我们：无后端静态页，**真实计数不存在，伪造数字违反本项目「不编造数据」底线**。
- 替代：社会证明改用公开事实标签——「中考核心实验」「课标必做」+ 教材章节出处（meta 已有人教版 PEP 依据）。
- 倾向：计数**不做**；课标/中考标签**做**（零成本、真实）。

### 4. 使用最多 / 最新发布排序——【不做；本地最近使用缓做】
- 它：三种排序。
- 我们：无统计无发布时间轴，做不了也不造假。「教学进度」排序由第 1 条章节视图覆盖。
- 替代：localStorage「最近使用」置顶（纯本地、真实），可选项。
- 倾向：云端排序**不做**；最近使用**缓做**（二期顺手项）。

### 5. 资源类型分层（探究实验/学案/互动课件）——【不做分类，吸收学案】
- 它：三类资源并存，按类型筛选。
- 我们：只有一种资源（3D 探究实验），分类无意义；学案的内容结构已被第 2 条吸收。
- 倾向：**不做**。

### 6. 教师端 / 学生端账号分层——【不做账号；做演示模式】
- 它：教师端（公共库+私有课件+自建沙盒+布置）与学生 APP 分层，账号体系支撑。
- 我们：免费开放静态站，无后端无账号，这是定位不是缺陷。
- 替代：课堂投影真实需求 → 「演示模式」：一键全屏、隐藏参数面板只留场景与读数、大字号。纯前端可实现。
- 倾向：账号分层**不做**；演示模式**做**（二期，教师场景实打实）。

### 7. 测评产品线——【不做系统；结论自测缓做】
- 它：独立测评产品（入口已见，内部未验证）。
- 我们：无题库无判分后端。
- 替代：实验指导末尾放 1 道结论自测选择题（如 A2「阻力全部消失，小车将？」）即时反馈，纯前端、每实验一题，服务复习闭环。
- 倾向：测评系统**不做**；单题自测**缓做**（二期可选，先观察第 2 条落地后的反馈）。

### 8. 题型资源（形杯问题/压强切割系列）——【缓做：参数预设】
- 它：把中考题型做成独立互动资源（形杯问题 4 条合计 133k 使用量，说明题型需求真实）。
- 我们：不新建题型实验，但可把**典型题设做成参数预设**：如 A4 的「容器形状×液体密度」组合就是形杯问题；A1 的 θ/L/μ 组合可对应典型计算题。JSON 加 presets 字段（每实验 3~5 个），滑杆区一键载入。
- 倾向：**缓做**（二期，内容编写量不小，先做第 1、2 条）。

### 9. 同一实验多版本（2D/3D 并存）——【不做】
- 它：平面镜 2D 380.3k vs 3D 679.4k。
- 我们：每实验只做一版 3D，精力集中。**关键数据点：3D 版使用量高于 2D 版约 79%，验证本项目 3D 路线**（交 CEO 决策表引用）。
- 倾向：**不做**多版本。

### 10. 专题推荐运营位——【不做】
- 它：可收起「实验专题推荐」。
- 我们：无运营角色，25 个规模不需要推荐位。
- 倾向：**不做**。

### 11. 多端客户端——【不做；手机适配已有】
- 它：Win/Mac 客户端 + 学生 APP + 扫码手机体验。
- 我们：纯 Web + 响应式（<768px 抽屉规则已落），客户端无必要。可选小项：分享按钮生成固定链接二维码（GitHub Pages 地址固定，纯前端），方便教师手机扫码课堂演示。
- 倾向：客户端**不做**；二维码**缓做**（顺手项）。

### 12. 免费增值 / 仅看免费——【不做商业化；做定位声明】
- 它：首月 VIP ¥9.9，免费区引流。
- 我们：全部免费、免登录、免安装。「仅看免费」筛选对我们无意义（全免费），但**这本身是对 nobook 的差异化卖点**。
- 落地：页脚/关于区一句定位声明：「25 个中考核心实验 · 完全免费 · 无需登录 · 打开即用」。
- 倾向：商业化**不做**；定位声明**做**（零成本）。

### 13. 搜索——【不做】
- 它：库内未见搜索框，靠章节/知识点筛选（300+ 规模）。
- 我们：25 个规模，左侧页签 + 章节视图已覆盖查找需求。
- 倾向：**不做**（规模到 50+ 再议）。

## 四、使用量数据点（供 CEO 决策表）

切片内 Top 10：练习使用电流表 1162.9k ＞ 3d平面镜成像 679.4k ＞ 凸透镜成像 618.4k ＞ 组装电路 410.2k ＞ 阿基米德原理 402.7k ＞ 平面镜成像(2D) 380.3k ＞ 演示惯性 364.7k ＞ 阻力对运动 339.9k ＞ 测灯泡电功率 307.5k ＞ 滑轮组机械效率 290.7k。

1. **仪器操作练习是第一大需求**（电流表 1162.9k 断层第一）：我们 25 个全是探究型，缺「练习使用仪器」型。倾向不新增实验，但在 D1/D4 内加「读数练习」轻模式（缓做）。
2. **3D 版 > 2D 版**（679.4k vs 380.3k，+79%）：验证本项目 3D 路线。
3. **P1 扩展清单可用 nobook 使用量排优先级**（backlog 11 个中 7 个有数据）：E6 滑轮组 290.7k ＞ E1 二力平衡 241.6k ＞ E8 光的色散 240.4k ＞ E5 天平/密度 223k+46.1k ＞ E4 弹簧测力计 149.5k+重力质量 85k ＞ E2 海绵压强 104.1k ＞ E3 大气压 81.7k+活塞抽水机 114.5k。建议二期按此序。

## 五、倾向汇总

- **做（一期候选）**：①章节视图（数据已有）②实验指导抽屉（学案结构，内容半成）③课标/中考标签 ④免费定位声明
- **缓做（二期）**：演示模式、数据记录表、参数预设（题型）、最近使用、结论自测单题、读数练习轻模式、分享二维码
- **不做**：使用量/点赞计数（不造假）、云端排序、资源类型分类、账号分层、测评系统、多版本、专题运营位、客户端、搜索、商业化

> 设计侧总判断：nobook 最值得借的不是功能，是**「每个实验自带一份学案」的内容结构**和**「按教学进度组织」的查找逻辑**——两者我们的 JSON 数据都已具备原料，纯前端可落，不碰 3D 场景与物理引擎，不影响现有验收口径。
