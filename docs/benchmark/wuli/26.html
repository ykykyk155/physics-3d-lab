探究串并联电路中电流的特点

初中物理 · 电磁学 · 仿真实验

🎯 实验目的

通过测量串联电路和并联电路中不同位置的电流，归纳两种电路中电流的规律。

📐 实验原理与结论

  • 串联电路中：电流处处相等，即 IA = IB = IC = ID
  • 并联电路中：干路电流等于各支路电流之和，即 I干 = I1 + I2
  • 电流表要与被测电路 串联，电流从"+"接线柱流入、"−"接线柱流出
  • 测量前要估计电流大小，选择合适量程

🔬 实验器材（本仿真）

器材参数
电源6 V
灯泡 L₁R₁ = 10 Ω
灯泡 L₂R₂ = 20 Ω

🕹️ 操作说明

  • 点击页面上方标签，切换「串联电路」和「并联电路」
  • 先点击电路中的开关 S，使电路闭合（开关杆变水平）
  • 再点击电路图上标注的 A / B / C / D（或 a / b / c / d）位置，把电流表接入该处测量
  • 下方会显示当前位置的电流读数
  • 依次测量四个位置的电流，记录数据并比较
  • 再点击开关可断开电路，此时无法测量
  • 点击「↺ 复位」清空记录、重新开始

💡 观察要点

串联电路中，四个位置的电流读数完全相同——这说明电流在串联电路各处相等。并联电路中，干路两个位置的读数相同且较大，两条支路的读数之和等于干路电流——这说明干路电流等于各支路电流之和。
