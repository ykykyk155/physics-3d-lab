# DAY 163｜10/90 代码可视化短视频方案

## 1. 目标
你要的是一条原创、愿意看完并收藏的 16:9 代码动画，不是照搬参考故事或讲成完整课程；新例子用“工作群收到一句『重做』”。

## 2. 风格选项
- **A｜动态文字排版**（huashu `y5_kinetic_type`）：数字/金句突出，成本低；长篇全用文字易疲劳，以分层标题与语音时间戳增强可读性。
- **B｜故事型简笔动画**（huashu `y4_storytime`）：适合表演两种回应的后果、角色更有温度；成本中等，需原创角色、少量屏字与字级对齐。
- **C｜象形运动图形**（Lemo `pictogram-motion`）：因果路径符号化、记忆点强；成本最高，需处理本机 WSL 运行限制，原生风格 24fps。

## 3. 推荐与拟定分镜
本版按 **B** 展开：同一个人的手指，两次停在「发送」上，让观众亲眼看到哪一步可以改。以下为剪辑预算，最终以配音实长对齐：
- **0–10 秒｜同一条消息。** 开头群聊弹出「重做」。手指已经打完「昨天不是你说可以的吗？」却还没发送。口播：“看到这两个字，你第一句想回什么？”
- **10–26 秒｜两种回应。** 第一遍按下发送，对方开始翻昨天的聊天记录，待改的稿子没人动。画面退回同一个发送键；第二遍删掉草稿，问「最先改哪一页？」对方圈出第三页，光标落在那里。
- **26–37 秒｜给观众带走一句话。** 屏上用「10/90」区分已经发生的事和还能选的回应，只作记忆提示，不当作统计比例。留屏自问：“我下一句话，能让事情往前走一步吗？”
- **约 37 秒至结束｜片尾。** 完整展示并自然读完下段指定原句；若 5 秒不够就延长片尾，不加速、不截尾。读完后保持全句可见至少 1 秒。

## 4. 交付及制作规格
确认后交付约42秒 MP4 + 独立人声/合成音效 WAV；保留“365天成长计划 · DAY 163”，尾帧及配音逐字为“点赞 收藏 关注，明天我们继续分享Jack叔叔的会员内容”。不含音乐（后期自加）、封面、竖版或源工程。新项目采用 huashu v1.2.0 / Python / Playwright Chromium / FFmpeg；16:9 1920×1080、30fps、固定种子 `20261120`、帧时刻 `t=i/30`，禁未播种随机；cubic-bezier(0.22,1,0.36,1) 或 spring(m=1,k=240,c=24)。配音自动合成成熟男声；TTS WordBoundary 先取词级时间戳，逐字动效再用强制对齐校正字级时间；合成音效、无音乐。自选视觉变量：暖纸白/墨黑/朱橙、8%安全边距、商用许可 Noto Sans SC；标题/阐述/强调词分层，对比度≥4.5:1，≤12汉字/秒，按16:9视口缩放。WAV PCM 48kHz/24bit、−16 LUFS、TP≤−1.5dBTP；MP4：`-c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p -r 30 -colorspace bt709 -color_primaries bt709 -color_trc bt709 -c:a aac -b:a 256k -ar 48000 -movflags +faststart`。验收：首尾帧、最长行、转场接缝、裁切/透明度、WCAG/CPS、同帧双渲 SHA-256 一致。
