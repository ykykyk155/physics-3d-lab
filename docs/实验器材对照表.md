# 25 个场景 · 实验器材对照表（实物化用）

> 依据：人教版（PEP）八年级上/下、九年级全一册 **教师演示与学生分组实验的实际器材**，含教材插图里出现的器件名称。
> 用途：给 @3D渲染师 做 `props.js` 工厂函数时的**器材依据**（桌上摆什么就做什么），给 @设计总裁 定材质与构件上限时的**分母依据**（哪些件必须实物、哪些可省）。
> 三栏读法：**主要观看对象** = 学生眼睛必须落在这几件上，造型必须一眼认出、优先给构件预算；**可省略件** = 真实实验里有但 3D 里不必做或可压成一片几何体的，**省掉不算缺失**。

## 实物化的六个"一眼认出"判据（跨场景通用）

渲染师做工厂函数时，这几样最容易图省事做成几何体，而它们恰恰是学生识别器材的依据：

1. **小车必须有四个轮 + 车轴**，不能是方块；轮子中至少前后可见，A1/A2 的车要能滚。
2. **弹簧测力计 = 条式外壳 + 顶端挂环 + 下端挂钩 + 刻度面板 + 指针**；读数要看刻度线，不能只留数字标签。
3. **电表 = 方形壳 + 大圆白表盘 + 黑色细长指针 + 刻度弧 + 下沿三个接线柱**（电流表标 A，电压表标 V）。这是电学七个场景的识别锚点。
4. **灯泡 = 玻璃泡 + 内部灯丝 + 金属螺口（带螺纹）**，不发光时玻璃泡半透明显。
5. **酒精灯 = 玻璃壶身 + 灯芯 + 灯帽**，火焰做在灯芯口上方；F1/F2/F3 都靠它表达"相同热源"。
6. **烧杯/试管要有壁厚和刻度线**，玻璃带轻微反光；液面单独一层几何体（现有 F2/D5 已经这么做，方向对）。

## 给 @首席执行官(定方案) 的一条口径冲突，需要你定

**热学的"热源"是酒精灯，但 F1 的参数名是「等效吸热功率 100~300 W」**。这是我当初为了让平台时长成比例写的口径，现在实物化之后，学生看到的是酒精灯，滑杆上却写「260W」——**器材和参数会各说各话**。

已核过三个场景的实际参数，冲突**只在 F1 一处**：F2 用的是「火力 1~5 档」（无单位，本来就对），F3 用的是「吸收热量 Q = 15 kJ」（结果量，也没问题）。所以只有 F1 的 `power` 一个参数需要定。

三种处理，建议选第 1 种：

1. **F1 参数名改成「加热火力/加热强度」、单位去掉 W**（内部仍按比例算 `t = m·c·ΔT/P`、`t_platform = m·L/P`，P 只做内部系数）。与 F2 的「档位」写法统一，也贴近教材"用相同热源加热相同时间"的说法，避免学生追问"酒精灯多少瓦"。
2. 保留 W，在读数卡加一句"等效吸热功率（酒精灯 + 水浴热损失后）"。诚实但仍显生硬。
3. 把热源改成电加热器/电加热管（真实实验室也用），这样 W 名副其实。但会丢掉酒精灯这个高识别度器材。

改法 1 和 3 都只动 `附录A-实验清单.json` 里 F1 的一个 `label/unit`，不动公式、量程、default 与验收。你定一个我立刻改表。
