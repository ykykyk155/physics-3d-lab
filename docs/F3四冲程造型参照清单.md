# F3 四冲程汽油机 · 造型与状态参照清单

> 依据：人教版九年级全一册 **第十四章 第2节 热机** 四冲程汽油机示意图（另参第十三章「内燃机的应用」）。
> 用途：给 3D渲染师 重做 F3 气缸造型的唯一参照，位置关系 + 运动方式 + 四冲程状态都写到可直接照做的程度。
> 已定不动的东西：曲轴角单参数解析驱动、活塞位置按 360°、气门与冲程判定按 720°、标签位置、气缸半透明。

## 一、静态结构：六类要素的位置关系

| # | 要素 | 位置（相对气缸） | 造型要点 |
|---|---|---|---|
| 1 | **气缸筒** | 竖直放置，中心轴 = Y 轴 | 圆筒，内壁可见；整体半透明（沿用现 opacity≈0.28），能看清内部活塞 |
| 2 | **缸盖** | 气缸**顶端**封口的厚圆盘/方块，与缸筒同轴 | 缸盖上有三个开孔：左孔装进气门、右孔装排气门、正中孔装火花塞 |
| 3 | **进气门** | 缸盖**左侧**（本演示统一取「进左排右」，与教材图一致） | 由「气门杆 + 气门头（disc）」组成，杆沿 Y 轴竖直穿过缸盖；**关闭时气门头贴在缸盖下表面座圈上，开启时气门头向下伸入缸内**，座圈处出现可见环形缝隙 |
| 4 | **排气门** | 缸盖**右侧**，与进气门左右对称 | 结构与进气门完全相同，同样向下开启伸入缸内 |
| 5 | **火花塞** | 缸盖**顶部正中央**（在两气门之间、偏上） | 陶瓷体（浅色）+ 金属壳（灰）+ 电极尖端伸入缸内**燃烧室顶部中央**；点火时在两电极间发出短促亮闪 |
| 6 | **进/排气管** | 进气门左侧向上接一段**进气管**（通向外/左上方）；排气门右侧向上接一段**排气管**（通向外/右上方） | 管径与气门杆协调；这两根管是"哪个门是进气、哪个是排气"最直观的判据，**必须有**，否则两颗气门无法区分 |
| 7 | **活塞** | 缸筒**内部**，外圆面贴近缸壁（留少量间隙可见） | 短圆柱，顶面是燃烧室下边界；活塞体内画出 2~3 道活塞环槽增加真实感 |
| 8 | **活塞销 → 连杆 → 曲轴** | 活塞**中下部**有活塞销；连杆大头接**曲柄销** | 连杆是细长杆，小头连活塞销、大头连曲柄销，**可绕两端转动**（随曲轴摆动倾斜，不能做成竖直固定的杆） |
| 9 | **曲轴 + 飞轮** | 缸筒**正下方**的曲轴箱内，曲轴主轴颈沿 Z 轴（朝向相机外） | 曲柄销分布在以主轴心为圆心的圆周上（半径 r）；曲柄臂 + 一个圆盘状**飞轮**（飞轮加几道辐条/配重块，让旋转看得出来）；**曲柄销相位 = 曲轴角 φ** |

**几何比例建议**（避免缸体过扁）：缸径 D ≈ 1.2，行程 2r ≈ 1.2（即 r ≈ 0.6），连杆长 l ≈ 2.0，`r/l ≈ 0.3`（在已定的 0.25~0.3 区间内取偏上值，连杆倾斜更明显、更像教材图）。

## 二、运动方式

### 活塞（已实现，此处仅作对照校验）
用曲柄连杆公式，**`s` 是活塞自「上止点」向下移动的位移**（不是自下止点起算，别看错）：

```
s = r·(1 − cos φ) + (r²/(2l))·sin²φ
piston.position.y = topY − s
```

- φ=0 时 s=0 → 活塞在**最上方**；φ=180 时 s=2r → 活塞在**最下方**。
- **约定 φ=0°（及 φ720=0°）为上止点 TDC、吸气冲程的起点**，四个冲程对应表以此为准。请在代码注释里写死这个约定，否则整套相位会错 180°（吸气画成压缩）。
- 活塞每转 360° 上下各一次（一个循环内活塞顶→底→顶→底→顶，共两次下行两次上行）。

### 气门（本次要补的核心）
气门升程随曲轴角解析给出，**用正弦半波，峰值在所属冲程中点**，不要做成"开/关瞬跳"，也不要靠文字标签变化糊弄：

```
进气门升程 lift_in(φ720) = sin(π · φ720 / 180)      当 0 ≤ φ720 < 180   （吸气冲程）
                        = 0                          其他区间
排气门升程 lift_ex(φ720) = sin(π · (φ720 − 540) / 180)  当 540 ≤ φ720 < 720 （排气冲程）
                        = 0                          其他区间
```

`φ720 = φ mod 720`；气门头世界坐标 Y = 关闭位 − lift × 最大升程（建议最大升程 ≈ 0.12~0.15，视觉上明显、又不至于顶到活塞）。

> **铁律：压缩与做功两个冲程，两颗气门必须升程为 0（全闭）。** 学生就是靠"两个门都关着"来区分压缩/做功与吸气/排气的。

### 火花塞
点火发生在**做功冲程起点附近**（φ720 ≈ 360°，活塞到达上止点后即将下行）。视觉：360° 起持续 20°~40° 曲轴角的电极亮闪 + 缸内亮度峰值，然后迅速衰减。压缩冲程末尾可以有轻微预发光，但**明显的闪只在做功起点**。

## 三、四个冲程的完整状态对照表（重拍四张图的验收依据）

| 冲程 | 曲轴角 φ720 | 活塞运动 | **进气门** | **排气门** | 火花塞 | 缸内/气体表现 | 能量转化 |
|---|---|---|---|---|---|---|---|
| **吸气** | 0 → 180° | 上止点 → **下行** | **开启**（升程 0→峰→0，门头明显伸入缸内、座圈留缝） | **关闭** | 不点火 | 混合气体沿**进气管→进气门**流入，缸内偏淡蓝/浅色，可加流向箭头 | 无（靠飞轮惯性） |
| **压缩** | 180 → 360° | 下止点 → **上行** | **关闭** | **关闭** | 不点火 | 气体被压缩：缸内颜色**逐渐变深/变暖**，体积明显变小 | 机械能 → 内能 |
| **做功** | 360 → 540° | 上止点 → **下行** | **关闭** | **关闭** | **起点处点火闪光** | 燃烧：缸内**最亮最红**（顶盖附近亮度峰值），燃气推动活塞下行 | 内能 → 机械能（唯一对外做功） |
| **排气** | 540 → 720° | 下止点 → **上行** | **关闭** | **开启**（升程 0→峰→0） | 不点火 | 废气沿**排气门→排气管**流出，偏灰褐色，可加流向箭头 | 无（靠飞轮惯性） |

### 肉眼必须分得出差别（CEO 的硬要求）
四张图不能只有标签不同。判据按优先级：

1. **气门升程**：吸气那张左侧气门开、右侧门关；排气那张相反；压缩和做功两张两门都关 —— 这三态是硬差别。
2. **活塞高度 + 冲程方向**：同 φ720 下活塞位置不同；建议在活塞或连杆旁加一个**上下方向箭头**表示当前运动方向（教材图都有这个箭头）。
3. **缸内亮度/颜色**：压缩渐深 → 做功起点最亮并带火花塞闪光 → 排气灰暗，四张各不相同。
4. **曲轴角标签**（现有，保留）：吸气 90° / 压缩 270° / 做功 450° / 排气 630° 各取冲程中点，四张图曲柄销相位应肉眼可见不同。

## 四、和现有实现的衔接（不要动的东西）

- `heatQ` / `qTotal` / `wUseful` 参数与动态上限（`maxFactor: 82.8`）**保持不变**；四冲程造型与比热容三根条互不影响。
- 冲程枚举仍是 4 档分段按钮：选中某冲程时把曲轴角**直接定位到该冲程中点**（φ720 = 90/270/450/630），这样暂停状态下点按钮就能拍到四张标准图；`rpm>0` 时枚举变只读跟随。
- 曲轴转速上的「只有做功冲程对外做功」：保留现有实现（做功段转速略升、其余靠惯性），这条不因为改造型而调整。
- 气缸保持半透明；但**缸盖建议不透明或低透明**，否则气门杆和火花塞穿模看不清——教材图里缸盖是实心的。

## 五、气门左右朝向：不可核实的绘图约定（重要）

「左进气门、右排气门」**不是物理事实，是教材插图的绘图惯例**，且各版本、各出版社的图并不统一（有的进左排右，有的相反）。本轮两次在线检索均取不到人教版第十四章那张原图，**无法确认课本朝向**，因此：

- 现实现取「进左排右」，**镜像与否都不影响物理正确性**，不要为它改动任何逻辑。
- **真正不可错的三条硬对应**（镜像时必须整体一起翻，不能只翻一边）：
  1. 与**进气管**相连的那颗门 = 进气门，只在**吸气冲程（φ720 0–180）**开启；
  2. 与**排气管**相连的那颗门 = 排气门，只在**排气冲程（φ720 540–720）**开启；
  3. 火花塞始终在两颗气门**正中间**，点火在 φ720≈360°。
- 也就是说：判据是「门 ↔ 管子 ↔ 冲程」的配对关系，不是屏幕左右。只要配对不乱，左右随便定。

**标准做法（CEO 已采纳，非建议项）**：「进气 / 排气」字样直接标在**进、排气管的管口**上，不标在气门盘上；开启的那颗门配一个**穿过管口进/出缸的流向箭头**（吸气朝缸内、排气朝缸外）。教材图就是用管口 + 流向箭头表达的，学生看管口比看左右可靠得多。这一条同时解决三件事：气门盘被缸盖挡住看不清开合、两个气门标签在缸盖上沿互相压字、以及左右朝向无法核实的问题。

## 六、一句话版

缸盖顶上「**进气门、排气门分居两侧，正中火花塞**」三件套 + 两侧各伸一根进/排气管（**左右朝向是绘图惯例，不作验收项，见第五节**）；气门是**竖直向下开**的杆+盘结构，**连进气管的那颗只在吸气开、连排气管的那颗只在排气开、压缩做功两门全闭**；「进气/排气」字样标在管口，开阀时配穿过管口的流向箭头；活塞用曲柄连杆公式（**φ=0 定为上止点**）在缸内往复，连杆倾斜摆动连到下方曲轴的曲柄销，曲轴带飞轮转；压缩缸内渐深、做功起点火花塞闪一下且缸内最亮；四张图的差别靠气门升程 + 活塞位置 + 缸内亮度 + 运动方向箭头，肉眼直接能分。
